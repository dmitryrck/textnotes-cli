# Example skills

Example skills to be used with agents.

## `textnotes.md`

Place in `~/.agents/skills/textnotes/SKILL.md`.

General purpose skill to save and search your notes using an agent.

Requires the CLI in the `PATH`, or you can update the skill with its location.

## `youtube-textnotes.md`

Place in `~/.agents/skills/youtube-textnotes/SKILL.md`.

Also requires the CLI in the `PATH`, but also `yt-dlp`.
